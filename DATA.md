# Data dictionary

All quantities are per planning period unless stated. Money is in USD inside the model
and SAR in the paper (3.75 SAR/USD). City order is the same in every file and is given
by `cities` in `realdata.json`.

## Inputs

| File | Contents | Source / class |
|---|---|---|
| `population.json` | `nodes`: for each of the 24 nodes, the governorate it serves, its 2022 population, whether the compiling page labels it a census figure, and the page URL. `region_totals_census_2022`: GASTAT region totals used as a check. `national_ewaste`: 595 kt (2019), used only for comparison. | Official (Saudi Census 2022 via Saudipedia/Wikipedia; GASTAT via GLMM; Regional E-waste Monitor for the Arab States 2021) |
| `realdata_original.json` | The study data as received: `cities`, the original 24 x 6 `ewaste` matrix (t/period) and `dist` (24 x 24 road km). The matrix is kept for comparison only; its period totals set the collection volume. | Study data; distances measured (Google Maps Distance Matrix API) |
| `realdata.json` | Model input written by `make_generation.py`: `cities`, `ewaste` (24 x 6 collected tonnes, period volume allocated by population, whole tonnes, period totals preserved), `dist`. | Derived |
| `params_complete.json` | Every parameter the model uses, written from the code by `make_params.py`, with a `_provenance` block classing each input. | See the parameter table in Section 5.1 and Table S4 |
| `model.py` (constants) | Prices, costs, capacities, demands, fuel and vehicle parameters, learning rate, staffing floor, solver settings. Capacities, the staffing floor, mu and the collection-centre operating cost are grouped in `ASSUMED`. | Mixed; see the parameter table in Section 5.1 |

## Outputs (all regenerated by `run_all.sh`)

| File | Contents |
|---|---|
| `stage1.json`, `stage1_solve_log.json` | Stage 1 siting, assignment shares, peak loads, variants with and without the equity rule; CBC solve log with model sizes |
| `results.json` | Payoff matrix, bounds, compromise, scalarisations, learning on/off, sensitivity, recovery mandates, single-facility loss; `solve_log` |
| `extra.json` | Allocation grid, transport probe, Monte Carlo summary; `solve_log` (Monte Carlo solves appended) |
| `mc_rows.jsonl` | One line per Monte Carlo draw, with its solve log |
| `diag_mc.json` | Diagnosis of infeasible draws (empty when every draw is feasible) |
| `lowvol.json` | Lower-volume case on its own bounds; physical feasibility of infeasible sensitivity cases; captive loads |
| `radius.json` | Maximum profit with and without the coverage radii |
| `equity_enum.json` | All equal-cost segregation sitings under the fixed compromise schedule |
| `tied_maxprofit.json` | The same sitings at maximum profit, schedule free |
| `equity_regional.json` | Worker-periods by region with and without the equity rule; employment-share floor sweeps |
| `joint.json`, `joint_sites.json` | Joint siting model (maximum profit and compromise) and the compromise on its sites |
| `recovery.json` | Profit decomposition by mandate; processing-cost and yield grid; break-even costs |
| `caputil.json` | Capacity utilisation (throughput / capacity) by tier at the maximum-profit design and the compromise, as distinct from the operational-utilisation objective $Z_2$; `solve_log` |
| `employment.json` | Workforce by period; staffing-floor sweep |
| `lr_sweep.json`, `lr_solve_log.json` | Learning-rate sweep and its solve log |
| `bench/` | Core runs, equity enumeration and radius check at the benchmark transport cost (`run_bench.sh`), each with its `solve_log` |
| `model_sizes.json` | Model sizes, software versions and hardware |
| `numbers.json`, `numbers.tex` | Every number quoted in the paper, as generated by `make_numbers.py` (JSON and LaTeX macros) |
| `supp_tables.tex` | Every supplementary table, generated by `make_supplement.py` |
| `figures/` | Figures, generated by `make_fig1.py`, `make_map.py`, `make_figures.py` |
| `logs/` | Console output of each step of `run_all.sh` |

Each `solve_log` entry records the solver status, `sol_status` (1 optimal within the gap,
2 stopped by the time limit, -1 infeasible), wall-clock seconds and, where a stopped solve
was re-solved, `superseded: true`.
